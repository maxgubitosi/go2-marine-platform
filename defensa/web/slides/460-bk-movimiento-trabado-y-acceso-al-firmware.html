BBackup: limitaciones del robot

Por qué no se mueve como le pedimos

Síntoma El robot sigue la forma de la consigna (r > 0,95) pero con retardo (τ = 0,45–0,95 s) y amplitud reducida (g ≈ 0,62). El movimiento se percibe trabado.
Descartado No es el camino de comando: la fidelidad entre consigna y comando enviado es > 0,9999. Lo que sale de nuestro software llega intacto.
Hipótesis El desacople se introduce en el control interno del Go2, al que no tenemos acceso directo. El patrón (fase + escala, sin deformación) es el de un sistema con lazo propio, no el de un error aleatorio.
Verificación Ground truth externo (OptiTrack) para separar la respuesta física real de las señales internas del robot, y barrido de frecuencia para reconstruir la respuesta del lazo.

Al no poder removerla, la limitación se volvió parte del modelo: θreal(t) ≈ g·θcmd(t−τ) + b.
